# Changelog

## 0.5.0
- Fix `sensor.novafos_water_consumption` statistics going negative. 0.3.0-0.4.1 imported the hourly history into the sensor's own statistics while the recorder compiled the same statistic from the sensor's state; the recorder started its own series at 0 underneath the imported sums. The integration no longer writes the sensor's statistics: the recorder owns them, and the hour-by-hour history lives only in the external statistic.
- One-time repair on the first start after upgrading: the sensor's statistics are rebased so every hour's sum equals the running total and the recorder continues from there. If the recorder never compiled the sensor, the imported rows are removed instead.
- **The external statistic is now `novafos_watts:water_consumption`** ("Novafos water consumption (Watts On)"). The old id `novafos_water:water_consumption` belongs to the separate, older Novafos integration (domain `novafos_water`), and both were writing to it. The full history is imported into the new id on the first start. Point Energy dashboard sources and statistics cards that should show this integration's data at the new id; this integration no longer writes the old one.
- Tests under `tests/` (pytest-homeassistant-custom-component), run by a GitHub workflow.

## 0.4.1
- Add a re-authentication screen: when the saved login stops working, Home Assistant now offers a form to paste a new refresh token (it checks it is the same Watts account) instead of leaving the integration broken.
- A 401 from the API now triggers one retry with a freshly refreshed access token; only a second 401 counts as a login failure.

## 0.4.0
- `sensor.novafos_water_consumption` now has `daily` (last 30 local days) and `hourly` (last 48 hours) attributes in m³, for templates and cards. They are excluded from the recorder database.

## 0.3.0
- Backfill the hourly history into the long-term statistics of `sensor.novafos_water_consumption` itself, not only the separate `novafos_water:water_consumption` statistic. Home Assistant cannot backfill past states, so the entity's state graph still starts at setup. (Withdrawn in 0.5.0: it made the sensor's statistics go negative.)

## 0.2.2
- Publish a GitHub Release for every version tag (workflow), so HACS shows real version numbers instead of commit hashes.

## 0.2.1
- Add a brand icon (`brand/icon.png`, generated by `tools/make_icon.py`) so Home Assistant and HACS stop showing a placeholder. Needs a Home Assistant version that loads local brand images from custom integrations.

## 0.2.0
- Use the real Watts API: `?startDate=` on consumptions, short field names (`sd`/`ed`/`vol`/`mq`), backend user id from `users/api/v3/User`.
- Volumes are cubic metres, whatever the device metadata says.
- Sensors: consumption, last full day, last 7 days, this month, this year, data until, token expires.
- Import hourly external statistic `novafos_water:water_consumption` for the Energy dashboard.
- `tools/login.py probe` reuses the saved token.
